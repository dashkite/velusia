# DashKite Velusia

*Web Components For Linkables*

[![Hippocratic License HL3-CORE](https://img.shields.io/static/v1?label=Hippocratic%20License&message=HL3-CORE&labelColor=5e2751&color=bc8c3d)](https://firstdonoharm.dev/version/3/0/core.html)

Velusia provides a collection of functional and reactive components, gadgets, and media handlers for building interactive user interfaces.

## Installation

Use your favorite package manager:

```bash
npm install @dashkite/velusia
```

## Usage

Import and use the components in your application.

```coffeescript
import "@dashkite/velusia"
```

## Status

Not suitable for production use. Please report any issues on the [GitHub repository](https://github.com/dashkite/velusia).
